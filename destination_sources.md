## 7. Struktur Firestore Subcollections & Data Travel Kaya

Untuk setiap dari 50 destinasi wisata, data travel diperkaya dengan dokumen detail dan 3 subcollection di Cloud Firestore:

### Struktur Path Firestore:
1. `destinations/{destinationId}`
   - `short_description` (String): Ringkasan singkat mengenai esensi dan keunikan destinasi.
2. `destinations/{destinationId}/attractions/{attractionId}`
   - `name` (String): Nama hal menarik / objek wisata.
   - `description` (String): Deskripsi ringkas daya tarik.
   - `image` (String): URL gambar terverifikasi dengan fallback.
   - `category` (String): Kategori (Budaya, Alam, Aktivitas, Bahari, Sejarah).
   - `estimated_cost` (Integer): Estimasi biaya tiket masuk / aktivitas dalam Rupiah.
   - `source` (String): Sumber referensi resmi (Indonesia.travel / Dinas Pariwisata).
3. `destinations/{destinationId}/accommodations/{accommodationId}`
   - `name` (String): Nama penginapan / hotel / resort / homestay terverifikasi.
   - `type` (String): Tipe akomodasi (Hotel, Resort, Villa, Homestay, Glamping, Ecolodge).
   - `location` (String): Area/kawasan akomodasi.
   - `price_range` (String): Rentang estimasi harga per malam (contoh: `Rp 800.000 - Rp 1.500.000 / malam`).
   - `rating` (Double): Rating ulasan (3.5 - 5.0).
   - `image` (String): URL gambar representatif akomodasi.
   - `source` (String): Sumber referensi.
4. `destinations/{destinationId}/local_foods/{foodId}`
   - `name` (String): Nama kuliner tradisional / hidangan khas lokal.
   - `description` (String): Deskripsi cita rasa dan bahan utama.
   - `price_range` (String): Estimasi kisaran harga per porsi (contoh: `Rp 25.000 - Rp 50.000 / porsi`).
   - `location` (String): Rekomendasi area berburu kuliner.
   - `image` (String): URL gambar kuliner dengan fallback.
   - `source` (String): Sumber referensi kuliner.

### Ringkasan Volume Data:
- **Total Destinasi**: 50 dokumen
- **Total Short Description**: 50
- **Total Hal Menarik (Attractions)**: 150 dokumen (3 per destinasi)
- **Total Tempat Menginap (Accommodations)**: 150 dokumen (3 per destinasi)
- **Total Kuliner Lokal (Local Foods)**: 150 dokumen (3 per destinasi)
